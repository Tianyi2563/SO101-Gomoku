## 验证证据

最新累计76项离线测试通过。覆盖合成图、AI战术、SO101模型短路径、标定误差、日志损坏/落盘失败/截断、真实子进程退出后的任务对账。示例data/offline-tools/final-20261117中，重启前后机器人任务数均2，对账后棋局版本3；图像为合成示意。
