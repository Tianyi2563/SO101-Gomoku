## 实际调用顺序

1. IK：get_robot_state → move_tip(axis="+y", distance_mm=2) → get_robot_state → stop_motion → LLM总结。
   - 求解器返回整步2mm；控制器首次返回时FK估计+y位移约1.876mm，随后状态查询约1.961mm。这是现有控制器到位容差/Mock跟随的影响，不声称零误差。
   - 记录：runs/20261019_200533_093500/trace.jsonl。
2. 视觉：get_robot_state → detect_object("black ball") → track_object(1) → stop_tracking → LLM总结。
   - 检测成功；视觉误差从(du,dv)=(-40,-30)px变为(-35,-26)px，欧氏误差50px降至约43.6px。
   - 三步有界伺服后converged=false；模型明确总结未收敛，没有冒称已经对准。
   - 记录：runs/20261019_200614_064349/trace.jsonl。
3. 预设与夹爪：list_presets → get_robot_state → move_to_pose("stand") → get_robot_state → set_gripper(55) → stop_motion → LLM总结。
   - 工具全部返回ok=true；模型说明Mock模式、没有实体动作。
   - 记录：runs/20261019_200737_217058/trace.jsonl。

运行前glm-4.6v-flash两次返回HTTP429；第二次可见提供方错误码1305“该模型当前访问量过大”。失败记录保留，不计入成功验收。随后改用同平台glm-4-flash成功，程序默认模型也改为该模型。
